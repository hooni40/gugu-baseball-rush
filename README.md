# 구구 야구단 타임런

구구단 정답 시간으로 홈런·3루타·2루타·1루타가 정해지는 Android 오프라인 게임입니다. 기존 구구 야구단과 별도로 설치됩니다.

**[설치용 APK 다운로드](https://github.com/hooni40/gugu-baseball-rush/releases/download/v1.0.1/gugu-baseball-rush-1.0.1-debug.apk)**

[릴리스 안내·검증 결과·실제 Android 플레이 영상](https://github.com/hooni40/gugu-baseball-rush/releases/tag/v1.0.1)

1.0.1 / Android 7 이상 / 약 13.4 MB / 개인 설치 테스트용 Debug 서명.

보통은 2·3·4·6초, 빠르게는 1·2·3·5초, 느리게는 3·4·5·7초입니다. 오답이나 시간 초과는 스트라이크이며 6타석을 마치면 종료됩니다.

APK를 내려받아 설치하고 **플레이 볼! → 단 선택 → 경기 속도 → 6타석 경기 시작**으로 플레이합니다. 물리 기기와 실제 소리 청취는 미검증이며 자세한 범위는 릴리스에 표시했습니다.
