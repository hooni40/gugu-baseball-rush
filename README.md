# 구구 야구단 타임런

구구단 정답을 맞히는 속도로 홈런·안타가 결정되는 Android 오프라인 야구 게임입니다. 숫자판에 답을 넣고 확인하면 귀여운 사람 선수들이 타격하고 달립니다.

## Android 다운로드

**[구구 야구단 타임런 1.1.0 APK 설치 파일](https://github.com/hooni40/gugu-baseball-rush/releases/download/v1.1.0/gugu-baseball-rush-1.1.0-debug.apk)**

- Android 7.0 이상 / 버전 1.1.0 (versionCode 3)
- 12,976,136 bytes / 개인 설치용 Debug 서명
- [화면·플레이 영상·검증 결과와 설치 안내](https://github.com/hooni40/gugu-baseball-rush/releases/tag/v1.1.0)
- 기존 타임런을 삭제하지 말고 업데이트로 설치하면 기록을 유지할 수 있습니다. 원래 ‘구구 야구단’과는 별도 앱입니다.

APK를 내려받아 열고, Android가 요청하면 해당 브라우저 또는 파일 앱의 ‘알 수 없는 앱 설치’를 허용합니다. 앱에서 **플레이 볼! → 경기 길이·구구단·속도 선택 → 경기 시작**으로 플레이합니다. 보관 중인 이전 경기가 있으면 ‘새 경기’에서 새 규칙을 시작할 수 있습니다.

## 1.1.0 경기 규칙

경기 길이를 **3회·6회·9회** 중 고릅니다. 매회 3아웃이면 주자를 정리하고 다음 회로 넘어가며, 선택한 마지막 회의 3아웃으로 경기가 끝납니다. 우리 팀 공격으로 점수를 쌓는 방식입니다.

| 속도 | 홈런 | 3루타 | 2루타 | 1루타 | 즉시 아웃 |
|---|---|---|---|---|---|
| 빠르게 | 1초까지 | 2초까지 | 3초까지 | 4초까지 | 4초 초과 |
| 보통 | 2초까지 | 3초까지 | 4초까지 | 5초까지 | 5초 초과 |
| 느리게 | 3초까지 | 4초까지 | 5초까지 | 6초까지 | 6초 초과 |

빠른 구간부터 적용합니다. 시간 내 오답은 스트라이크이며 3스트라이크도 아웃입니다. 시간 초과는 스트라이크 수와 관계없이 즉시 아웃입니다. 일시정지하면 문제 시간도 멈춥니다.

선수와 수비수를 약 12% 키우고 외곽선·표정을 다듬었습니다. 기존 기록과 미완료 6타석 경기는 보존하며, 새 경기부터 회차 선택과 새 규칙을 적용합니다.
